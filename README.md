# Generador de Paletas Interactivo

Aplicación web desarrollada como proyecto del **Módulo 1 - Fundamentos del Desarrollo Web** de Soy Henry.

El proyecto permite generar paletas de colores de forma aleatoria, seleccionando la cantidad de colores y el formato en el que se desean visualizar: **HSL o HEX**.

## 🚀 Funcionalidades

* Generación aleatoria de paletas de colores.
* Selección de 6, 8 o 9 colores.
* Visualización de colores en formato HSL o HEX.
* Conversión de colores HSL a HEX.
* Generación de una paleta inicial al cargar la página.
* Interfaz responsive para dispositivos móviles.
* Interacción mediante controles y botón de generación.

## 🛠️ Tecnologías utilizadas

* HTML5
* CSS3
* JavaScript
* Git
* GitHub

No se utilizan frameworks, librerías externas ni dependencias de terceros.

## 📥 Instalación y ejecución local

Para trabajar con el proyecto de forma local, es necesario tener instalado [Git](https://git-scm.com/).

### 1. Clonar el repositorio

```bash
git clone https://github.com/Lenta-Maximiliano/ProyectoM1_MaximilianoLenta.git
```

### 2. Ingresar al directorio del proyecto

```bash
cd ProyectoM1_MaximilianoLenta
```

### 3. Ejecutar el proyecto

El proyecto no requiere la instalación de dependencias ni herramientas adicionales, ya que está desarrollado con HTML, CSS y JavaScript.

Una vez clonado el repositorio, se puede abrir directamente el archivo `index.html` en un navegador web.

## 📖 Instrucciones de uso

1. Seleccionar la cantidad de colores que tendrá la paleta.
2. Seleccionar el formato de visualización: HSL o HEX.
3. Presionar el botón **"Generar paleta"**.
4. La aplicación generará una nueva paleta de colores de forma aleatoria.

La aplicación genera automáticamente una paleta inicial al cargar la página.

## 💡 Decisiones técnicas

* Se utilizó **HTML semántico** para organizar la estructura de la aplicación.
* Se utilizó **CSS Flexbox** para la distribución de los controles de configuración y **CSS Grid** para organizar las tarjetas de colores.
* Se implementó un diseño responsive mediante **Media Queries**.
* La generación de colores se realizó utilizando JavaScript y `Math.random()`.
* Se desarrollaron funciones independientes para generar colores HSL, generar colores HEX y realizar la conversión de HSL a HEX.
* Se mantuvo el proyecto sin frameworks ni dependencias externas para trabajar los fundamentos de HTML, CSS y JavaScript.
